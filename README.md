# دفتر النتيجة

واجهة عربية ثابتة للبحث في نتيجة الثانوية العامة 2026 برقم الجلوس أو بداية اسم الطالب، مع فلاتر للمحافظة والحالة والنسبة والنوع والمدرسة.

## البيانات والخصوصية

بيانات البحث العامة مضمّنة في `data/` على هيئة أجزاء JSON صغيرة، لذلك لا يرفع المستخدم أي ملفات ولا يحتاج إلى خادم تطبيق. بُنيت ملفات النشر بقائمة حقول مسموح بها فقط تشمل الاسم، رقم الجلوس، النتيجة، الدرجات، والمدرسة.

لا تتضمن النسخة المنشورة الرقم القومي، العنوان، تاريخ أو محل الميلاد، قسم الشرطة، رقم التنسيق، أو أي حقول شخصية حساسة أخرى موجودة في المصدر الأصلي. تبقى ملفات CSV وملفات قواعد البيانات الأصلية خارج Git.

## التشغيل المحلي

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`. لا تفتح `index.html` مباشرةً عبر `file://` لأن البحث يعتمد على تحميل أجزاء JSON عند الطلب.

## إعادة بناء فهرس النشر

يتوقع السكربت افتراضيًا وجود الملفين التاليين في `../csv_exports/`:

- `Stage_New_Search.csv`
- `SHREKAT.csv`

ثم شغّل:

```bash
node scripts/build-public-data.mjs
```

يمكن أيضًا تمرير مساري الملفين ومجلد الخرج بالترتيب. السكربت يستبدل مجلد `data/` المولّد بعد تطبيق قائمة الحقول العامة الصريحة.

## النشر

سير العمل في `.github/workflows/pages.yml` ينشر الموقع وبياناته الثابتة تلقائيًا إلى GitHub Pages عند الدفع إلى فرع `main`. إعداد `netlify.toml` يسمح بالنشر الثابت نفسه على Netlify دون أمر build.
