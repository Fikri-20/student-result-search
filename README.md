# دفتر النتيجة

واجهة عربية ثابتة للبحث في ملفات نتائج الثانوية العامة محليًا داخل المتصفح.

## الخصوصية

هذا المستودع يحتوي على الواجهة فقط. **لا ترفع ملفات CSV أو ملفات قاعدة البيانات إلى GitHub أو Netlify.** تحتوي الملفات الأصلية على أرقام قومية وعناوين منزلية. عند استخدام الصفحة، يختار المستخدم الملفات من جهازه وتتم القراءة والفهرسة داخل المتصفح فقط؛ لا يوجد رفع أو خادم بيانات.

## التشغيل

شغّل خادم ملفات ثابتًا من هذا المجلد، ثم افتح الصفحة في المتصفح. لا تفتح `index.html` مباشرةً عبر `file://` لأن المتصفحات تمنع Web Workers في هذا الوضع.

```bash
python3 -m http.server 4173
```

بعد فتح الصفحة اختر الملفين:

- `Stage_New_Search.csv` للبحث والإحصائيات.
- `SHREKAT.csv` للسجل الكامل.

الملفان كبيران؛ قد يستغرق بناء الفهرس عدة ثوانٍ، لكن الواجهة تظل متجاوبة لأن الفهرسة تعمل في Web Workers.

## النشر

المجلد جاهز لـ GitHub Pages وNetlify. النشر يتضمن ملفات الواجهة فقط، ويستمر اختيار ملفات CSV محليًا بعد فتح الموقع المنشور.

### GitHub Pages

ادفع هذا المجلد إلى مستودع GitHub. سير العمل الموجود في `.github/workflows/pages.yml` ينشر الموقع تلقائيًا من فرع `main`.

### Netlify

اربط المستودع بـNetlify بدون أمر build؛ ملف `netlify.toml` يحدد مجلد النشر الحالي.
